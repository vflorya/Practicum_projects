## Проект 5. Анализ активности пользователей Яндекс Книг
**Задача:** оценить поведение пользователей сервиса Яндекс Книги и проверить результаты A/B-теста интернет-магазина.  
**Инструменты:** SQL (подготовка данных), Python (pandas, scipy.stats,matplotlib.pyplot, numpy).  
**Что сделано:**  
- В SQL подготовлены данные о времени чтения/прослушивания пользователей Москвы и Санкт-Петербурга.
- Проверена гипотеза: тратят ли петербуржцы больше времени в приложении, чем москвичи (односторонний t-test).
- Составлена аналитическая записка с выводами о статистической значимости.
- Проведен анализ A/B-теста. Цель теста: оценить влияние изменений интерфейса на конверсию в покупку (целевое действие) пользователей, зарегистрировавшихся в декабре 2020 г. Ожидаемый эффект в 3 п.п. не достигнут. Фактический прирост (1.73 п.п.) оказался меньше запланированного минимального детектируемого эффекта (MDE = 3 п.п.)  
**Результат:** даны рекомендации по поведенческим паттернам пользователей и эффективности нового дизайна сайта.

## Проект 6. Анализ данных Яндекс Афиши, расчёт метрики и создание дашборда
**Ссылка на дашборд:** https://datalens.ru/at2ecsynx1jit-yandeks-afisha-analitika-biznes-pokazateley  
**Задача:** Выяснить причины изменения спроса на события, определить популярные категории, лидеров среди организаторов и площадок, сравнить мобильных и десктоп-пользователей, проверить статистические гипотезы.   
**Инструменты:** Python (pandas, numpy, matplotlib, seaborn, scipy.stats), Jupyter Notebook, DataLens (дашборд).  
**Что сделано:**   
· Проведена предобработка: конвертация валют (рубли, тенге), отсечение выбросов по 99-му процентилю, удаление дубликатов, создание новых признаков.
· Исследована сезонность: рост заказов к осени, сравнение летнего и осеннего периодов по типу мероприятий, устройствам, возрастному рейтингу; проанализирована динамика средней цены билета.
· Изучена осенняя активность (сентябрь–октябрь) по дням: DAU, заказы, средний чек, недельная цикличность.
· Выявлены топ-регионы и топ-партнёры по выручке и разнообразию событий.
· Проверены две гипотезы о мобильных пользователях (среднее число заказов и время между заказами) с помощью t-тестов.
· Построен дашборд с индикаторами, линейными графиками, структурами выручки и таблицами топ-сегментов, с фильтрами по валюте, дате, типу события и региону.
· Сформулированы общие выводы и рекомендации для продуктовой команды.
