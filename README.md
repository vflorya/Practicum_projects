## Проект 1. Отчёт в Google Таблицах для салона красоты
**Задача:** найти точки роста для увеличения прибыли салона за счет оптимизации скидок и ассортимента.
**Инструменты:** Google Таблицы  (сводные таблицы, формулы)
**Что реализовано:** 
- проанализирована структура доходов/расходов за 7 месяцев;
- оценена эффективность промокодов: частотность использования, влияние на выручку и недополученный доход;
- рассчитан средний чек по каждой промоакции;
- выявлены самые популярные услуги и товары для фокуса на продажах.
**Результат:** предложены стратегии по пересмотру скидочной политике и продвижению самых востребованных позиций.

## Проект 2. Дашборд по данным конференции TED
**Задача:** создать интерактивный дашборд для анализа выступлений TED: популярность тем, длительность, реакция зрителей и активность спикеров.
**Инструменты:** DataLens
**Что реализовано:**
- Метрики верхнего уровня: кол-во конференций, выступлений, спикеров, тем.
- Детализация по странам и конференциям (средняя длительность, макс. просмотры, аплодисменты, число выступающих).
- Топ-10 смешных выступлений и топ-20 популярных тегов.
- Анализ спикеров с наибольшим количеством аплодисментов (по роду деятельности).
- Детальный просмотр информации по каждому выступлению.
- Фильтры: страна, конференция, тег, дата записи.
**Результат:** готовый дашборд позволяет заказчику быстро находить инсайты о зрительских предпочтениях и оптимизировать формат мероприятий.

## Проект 3. Анализ объявлений о продаже жилой недвижимости
**Задача:** определить наиболее перспективные сегменты недвижимости в Санкт-Петербурге и Ленинградской области для планирования бизнес-стратегии.
**Инструменты:** SQL (DBeaver), DataLens (дашборд).
**Что сделано:**
- Проведена разведка данных в схеме `real_estate` (архив Яндекс.Недвижимости).
- Решены ad hoc задачи на SQL:
  - Выявлены сегменты с высокой привлекательностью на основе времени активности объявлений.
  - Проанализированы сезонные тренды (пики активности продавцов и покупателей) для планирования маркетинга.
- Доработан дашборд в DataLens по ТЗ заказчика (добавлены новые элементы и фильтры).
**Результат:** сформулированы рекомендации по выбору сегмента для входа на рынок и оптимальных сроков публикации объявлений.
